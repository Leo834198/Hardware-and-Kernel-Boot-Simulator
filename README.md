# Hardware-and-Kernel-Boot-Simulator
These .exe files simulate a text-based boot process, allowing you to see what happens within the kernel or hardware—among other things—before the device actually starts up. You can name this repository "hakBS" or use all caps: "HAKBS".

Our .exe files are hand-crafted using C++. Feel free to leave us a comment.

According to this repository, it serves to show how the bootloader loads the kernel and how the system loads while the hardware does the work, among other things.
